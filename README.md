## 一、适用范围与运营主体

卡片评级管理（以下简称“本 App”或“本服务”）用于授权人员管理卡片档案、图片、评级、证书和标签。交易功能是否可用，由所连接后台的配置和账号权限决定。公开证书可通过配套网站访问，内部管理功能需要授权账号登录。

本政策说明卡片评级管理 iOS App 及本运营者提供的配套 Web 管理系统、公开证书查询服务的信息处理方式。

### 服务地址与独立后台

本 App 支持填写服务地址，连接不同后台。登录信息、卡片资料、图片和操作请求会发送至你选定的服务地址；不同后台的账号、权限和业务数据相互独立。请仅连接你信任且获得授权使用的后台。

若后台由其他个人或组织独立运营，其对服务器数据的处理由该后台运营者负责，并适用其提供的隐私政策。App 开发者不会仅因提供客户端而自动取得其他独立后台中的业务数据。与某个后台有关的信息查询、更正或删除请求，可向该后台运营者提出；涉及本 App 的问题，可通过本文的联系方式联系本运营者。

## 二、我们处理的信息及用途

### 1. 账号与身份认证信息

为提供登录、权限管理、账号维护和安全验证，我们处理用户名、姓名或显示名称、账号角色、账号状态及密码验证信息。密码通过加密连接传输，服务端保存密码哈希而非明文密码。

App 在设备钥匙串中保存登录凭据，以维持登录状态；设备上还会保存服务地址、语言、显示偏好等设置。登录凭据按不同服务地址分别保存。拒绝提供必要的账号认证信息将无法使用内部管理功能，但不影响无需登录的公开证书访问。

### 2. 卡片与评级业务信息

我们处理你创建、编辑或上传的卡片信息，例如人物或主题、年份、品牌或系列、类别、卡片编号、限编、版本、描述、评级编号、评级分数、签字评分、评级备注和图片。这些信息用于卡片管理、评级、证书展示、搜索及标签生成。

请勿在卡片图片、描述或备注中上传与评级无关的身份证件、联系方式、面部照片或其他个人敏感信息。涉及他人的信息或图片时，请确保具有合法处理依据。

### 3. 图片与扫码信息

- 上传卡片图片或自定义标签 Logo 时，所选图片会发送至服务端并存储，用于相应业务展示和标签生成。
- 使用摄像头扫码或从相册选择图片扫码时，条码识别由设备本地完成；识别出的卡片编号等查询内容会发送到服务器查找卡片。扫码图片或摄像头画面不会仅因扫码操作被作为卡片图片上传。
- 你主动选择上传、保存或分享图片、PDF 标签时，会按照你的操作处理相应文件。分享给其他 App 后，该 App 的处理行为受其自身政策约束。

### 4. 设备、网络与操作记录

为维持安全、排查故障和追溯业务操作，服务端可能记录 IP 地址、请求时间、接口路径、客户端请求信息、操作结果及必要的错误信息。内部操作日志还可能包含操作者标识、角色及操作内容。

启用 Face ID 登录时，App 会生成用于本服务的随机设备标识，并将其与账号及登录凭据关联。该标识不是广告标识符，不用于跨 App 广告追踪。

### 5. Face ID 登录

Face ID 为可选功能，可在“设置”中开启或关闭。生物识别验证由 Apple 系统在设备上完成，本服务不读取、不接收、不存储面部图像、面部模板或其他生物特征数据，只使用系统返回的验证结果。

启用后，受设备系统保护的登录凭据用于重新获取登录会话；服务端保存对应凭据的哈希、设备关联信息及有效期。关闭该功能或删除账号时，相应登录凭据会被撤销。关闭 Face ID 不影响使用账号密码登录。

## 三、系统权限

本服务在你主动使用相关功能时申请必要权限：

| 权限或系统功能 | 使用目的 | 不允许时的影响 |
| --- | --- | --- |
| 摄像头 | 拍摄卡片图片、扫描二维码或条形码 | 无法拍照或实时扫码，仍可使用其他可用方式录入或查询 |
| 系统照片选择器 | 选择要上传的图片或用于识别条码的图片 | 无法完成相应的选图操作 |
| Face ID | 在启用后验证本人身份并重新登录 | 可继续使用账号密码登录 |
| 保存到照片图库 | 将你主动选择保存的证书二维码等图片写入照片图库 | 无法保存对应图片，不影响其他管理功能 |
| 本地网络（连接局域网后台时） | 与你配置的局域网服务器通信 | 无法访问该局域网后台 |
| 系统文件与分享功能 | 导出、保存或分享标签文件 | 不影响卡片管理及评级 |

你可以通过 iOS 系统设置管理已授权的权限。系统照片选择器仅向 App 提供你选择的内容，并不代表 App 获得整个相册的读取权限。

## 四、公开证书与信息披露

公开证书用于验证卡片评级结果。任何获得证书链接、二维码或有效评级编号的人，都可能查看证书中的卡片资料、卡片图片、评级编号、综合评分和签字评分等公开内容。

请在上传前确认拟公开的信息和图片适合公开访问。公开访问者可能自行保存或转发证书内容，本服务无法控制已被他人独立保存的副本。

## 五、委托处理、共享及第三方服务

本服务不出售你的个人信息。当前 App 不集成第三方广告、用户行为分析或跨 App 追踪 SDK，不读取广告标识符，也不为广告目的追踪你在其他 App 或网站的活动。本 App 不主动读取通讯录、位置、通话记录或短信。

为提供服务，数据库、图片文件存储、服务器及网络服务提供商可能依照我们的委托处理必要数据。我们要求其仅在提供服务所需范围内处理信息，并采取适当保护措施。

- 本运营者当前使用的云服务：阿里云，提供云服务器及相关基础设施服务。数据库和上传图片存放于本运营者配置的服务器存储中。阿里云的相关政策可通过[阿里云官方网站](https://www.aliyun.com/)底部的法律声明及隐私政策入口查阅。

除公开证书展示、你主动分享、提供服务所必要的委托处理，以及依法履行义务等情形外，我们不会擅自向其他组织或个人披露你的个人信息。若处理目的或接收方发生实质变化，将依法履行告知及其他必要程序。

## 八、删除账号

登录 iOS App 后，可进入“设置 → 删除账号”，输入当前密码及确认词 `DELETE`，并再次确认。该操作永久删除当前账号，不只是停用账号。

删除成功后：

- 删除账号资料和服务端关联的生物识别登录凭据，旧登录令牌在后续请求中失效。
- 当前设备清除登录凭据、Face ID 登录配置及本服务生成的设备标识，并返回登录页。其他设备的服务端访问失效，但其本地文件不会被远程擦除。
- 解除卡片的评级师指派，已保存的评分及修改记录中的关联账号标识作匿名化处理，相关结构化操作日志作脱敏处理。
- 组织的卡片、图片、评分和证书记录不随个人账号一并删除。手动录入在描述、备注或图片中的个人信息不会仅通过删除账号自动全部识别清除；如需处理，请联系我们。

删除账号无法恢复。最后一个管理员删除账号将影响组织继续管理系统，请事先确认存在其他管理员。

账号删除不会立即重写已有离线备份。备份中的历史数据按照本政策列明的备份期限到期清除，仅用于必要的恢复与安全目的。执行恢复时应再次落实删除要求，防止已删除账号重新启用。自行下载或分享的文件需由持有人自行管理。
